# CryptoCore

Учебная программа для шифрования и расшифрования файлов с помощью AES-128 в режиме ECB.

## Зависимости

- Python 3.10 или новее.
- pip — для установки проекта.
- setuptools — для сборки пакета.
- pycryptodome — для выполнения операций AES.
- Git — для хранения истории проекта.

Зависимости сборки и библиотека pycryptodome устанавливаются автоматически.
Для тестирования используется встроенный модуль unittest.

## Установка в Windows PowerShell

Откройте терминал в корневой папке проекта.

1. Создайте виртуальное окружение, если его ещё нет:

   ```powershell
   python -m venv .venv
   ```

2. Установите проект в это окружение:

   ```powershell
   .\.venv\Scripts\python.exe -m pip install -e .
   ```

3. Активируйте окружение:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

4. Проверьте доступность команды:

   ```powershell
   cryptocore --help
   ```

Если окружение уже активировано в PyCharm, достаточно выполнить:

```powershell
python -m pip install -e .
cryptocore --help
```

## Использование

Создайте файл plaintext.txt с произвольным текстом.

Шифрование:

```powershell
cryptocore --algorithm aes --mode ecb --encrypt --key 000102030405060708090a0b0c0d0e0f --input plaintext.txt --output ciphertext.bin
```

Расшифрование:

```powershell
cryptocore --algorithm aes --mode ecb --decrypt --key 000102030405060708090a0b0c0d0e0f --input ciphertext.bin --output decrypted.txt
```

Ключ должен содержать ровно 32 шестнадцатеричных символа, представляющих 16 байт. Для расшифрования используется тот же ключ.

Все аргументы обязательны. Нужно указать ровно одну операцию: --encrypt или --decrypt.

При успешном выполнении программа завершается с кодом 0.
При ошибках аргументов или ключа возвращается код 2.
При файловых ошибках или ошибках расшифрования возвращается код 1.
Сообщения об ошибках выводятся в stderr.

## Проверка полного цикла

После шифрования и расшифрования сравните файлы побайтово:

```powershell
python -c "from pathlib import Path; print('Файлы совпадают:', Path('plaintext.txt').read_bytes() == Path('decrypted.txt').read_bytes())"
```

Ожидаемый результат:

```text
Файлы совпадают: True
```

## Автоматические тесты

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют:

- восстановление текстовых, бинарных и пустых данных;
- добавление и проверку PKCS#7;
- обработку неправильной длины ключа и шифротекста;
- совпадение шифротекста с готовой реализацией ECB и PKCS#7 из pycryptodome;
- полный цикл через командный интерфейс;
- ошибки аргументов и файлового ввода-вывода.

## Структура проекта

- src/cryptocore/cli_parser.py — аргументы командной строки и выполнение операции.
- src/cryptocore/file_io.py — чтение и запись бинарных файлов.
- src/cryptocore/modes/ecb.py — обработка блоков и дополнение PKCS#7.
- src/cryptocore/__main__.py — точка входа.
- tests/ — автоматические тесты.

Примитив AES используется из pycryptodome. Разбиение данных на блоки по 16 байт, дополнение PKCS#7 и его проверка реализованы в проекте.
